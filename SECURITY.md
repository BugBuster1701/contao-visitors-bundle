# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.18.x   | :white_check_mark: |
| 1.16.x   | :x:                |
| 1.15.x   | :x:                |
| 1.14.x   | :white_check_mark: |
| < 1.14   | :x:                |

## Reporting a Vulnerability

If you think that you have found a security issue in Contao Visitors Bundle, please [open a security advisory](https://github.com/BugBuster1701/contao-visitors-bundle/security/advisories/new) on GitHub.

Never disclose any information about a vulnerability on the public web (blog posts, tweets, GitHub issues, etc.) before the vulnerability has been acknowledged and fixed in a new Contao Visitors Bundle version!

## Resolving process

For every report, we first attempt to confirm the vulnerability. When it is confirmed, the core team works on a solution following these steps:

* Acknowledge the security advisory
* Work on a patch
* Publish a security announcement on Contao Slack-> Extensions
* Ask the reporter to review the patch pull request
* Apply the patch to all maintained versions of Contao Visitors Bundle
* Release new versions for all affected versions
* Announce the new versions and the vulnerability on Contao Slack and Contao Forum

## Security advisories
Check the [security advisories](https://github.com/BugBuster1701/contao-visitors-bundle/security/advisories) for a list of all security vulnerabilities that were already found and fixed in Contao Visitors Bundle.
